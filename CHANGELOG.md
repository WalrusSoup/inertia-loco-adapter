# Changelog

## 0.0.1

Initial public release of `loco-inertia`.

- Axum middleware for Inertia page responses and protocol headers.
- Optional Loco pagination integration.
- Shared, partial, lazy, deferred, merge, and infinite-scroll props.
- Once props, deep/keyed merges, flash data, and browser-history directives.
- Optional root view rendering, Vite development assets, and Inertia SSR transport.
